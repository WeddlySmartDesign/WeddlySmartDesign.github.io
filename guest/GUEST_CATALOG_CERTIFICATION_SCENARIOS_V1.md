1. run the complete supported-state matrix at 360 / 390 / 430 mobile widths;
2. run Normal V1 without template editing;
3. run Stress V1 without template editing;
4. verify review/final parity;
5. verify common recipient context + existing RSVP;
6. verify no per-couple HTML/CSS/position/timing changes;
7. run real Android owner normal scenario and confirm <=5 minutes active owner time;
8. only then set `commercially-frozen`.
